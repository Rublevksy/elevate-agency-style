# 06 — HERO IS THE PRIMARY EXPERIENCE

The Hero is not simply a static landing section.

The Hero must become a scroll-driven cinematic sequence.

The visitor controls the progression through scrolling.

Scroll position must control the visual state of the scene.

The experience should feel like controlling a camera through an ELEVATE world.

Conceptual sequence:

SHOT 01
Initial ELEVATE environment.

SHOT 02
Camera begins moving.

SHOT 03
The MacBook/device becomes more prominent.

SHOT 04
The device changes state / opens / transforms.

SHOT 05
The camera approaches the display.

SHOT 06
The camera enters the display.

SHOT 07
The digital product/interface becomes the main visual world.

SHOT 08
The experience transitions naturally into Services.

This must feel like one continuous sequence.

It must NOT feel like:

image 1
→ fade
→ image 2
→ fade
→ image 3

or:

scroll
→ CSS translate
→ next section.

---

# 07 — SCROLL-DRIVEN CINEMATIC SYSTEM

The implementation must be genuinely controlled by scroll progress.

Possible technologies include:

- video scrubbing
- image sequences
- WebGL
- Canvas
- 3D
- DOM transforms
- CSS transforms
- Framer Motion
- GSAP
- Three.js
- controlled combinations of the above

Choose the technically appropriate solution for each scene.

Do not force one technology everywhere.

The important requirement is the EXPERIENCE, not the technology.

The animation must respond continuously to scroll position.

It must work when the user:

- scrolls slowly
- scrolls quickly
- stops halfway
- scrolls backwards
- changes direction
- enters the scene
- exits the scene

No jumps.

No uncontrolled snapping.

No broken intermediate states.

No animation that only looks correct when scrolling quickly.

The experience must feel controlled by the user's hand.

---

# 08 — ONE CAMERA

The Hero must behave conceptually as ONE CAMERA moving through ONE WORLD.

Avoid unrelated animations happening independently.

Camera movement, device movement, lighting, depth and content transitions must feel coordinated.

Prefer:

- perspective
- depth
- scale
- rotation
- position
- parallax
- camera movement
- controlled blur
- light movement
- environmental response
- object transitions

Use effects only when they support the camera story.

# 09 — MACBOOK / DEVICE

If the MacBook is used, it must feel like a real premium physical device.

Avoid crude CSS laptop approximations.

The device should have:

- believable proportions
- perspective
- depth
- chassis
- display
- realistic lighting
- realistic shadows
- reflections where appropriate

The device must feel physically integrated into the environment.

It must not look like a rectangular image placed on top of a background.

The device movement must be smooth.

Do not create a short artificial rotation that stops, freezes, then continues.

The movement must be tied naturally to scroll progress.

# 15 — INTERACTIVE PROJECT BUILDER

The visitor should progressively describe what they want.

BUSINESS TYPE
→ Automotive
→ Restaurant
→ Beauty
→ E-commerce
→ etc.

PROJECT TYPE
→ Website
→ E-shop
→ Application
→ Branding

PROJECT DETAILS
→ goals
→ desired functionality
→ style
→ requirements

VISUAL DIRECTION
→ relevant visual concepts

The visual concept step may use AI-generated images.

For example:

A visitor enters:

"Automotive"

The system may present several relevant website visual directions.

The visitor can inspect them and select one.

The selected visual direction becomes part of the project brief.

The final submission sends the complete project brief to ELEVATE.

IMPORTANT:

Do not implement the AI generation blindly.

First determine the best UX architecture.

If there are multiple genuinely different approaches, present 2–3 concrete options to the user.

The user chooses the direction.

Only then implement the selected approach.

Do not spend generation credits before approval.
