## 1. Безопасный слой (сначала, до всякой красоты)

Новый мир строится **рядом**, а не поверх. Прод не ломается ни на одном шаге.

```
src/components/bench/          новый мир
  Bench.tsx                    рельс, лента, окно чтения, защёлка
  BenchFrame.tsx               один кадр: пробитое окно + подпись
  BenchRail.tsx                перфорация (SVG pattern), деления
  marks.tsx                    пять знаков состояния
  bench-tokens.ts              --frame, --pitch, --density, плотности сцен
src/routes/bench.tsx           /bench — витрина нового мира, вне прода
```

Главная не трогается, пока `/bench` не пройдёт браузерный QA. Тот же приём, что
уже применялся в проекте для `/design`-зоны, и он себя оправдал.
