## 1. Безопасный слой (сначала, до всякой красоты)

Новый мир строится **рядом**, а не поверх. Прод не ломается ни на одном шаге.

```
src/components/bench/          новый мир
  Bench.tsx                    рельс, лента, окно чтения, защёлка
  BenchFrame.tsx               один кадр: пробитое окно + подпись
  BenchRail.tsx                перфорация (SVG pattern), деления
  marks.tsx                    пять знаков состояния
  bench-tokens.ts              --frame, --pitch, --density, плотности сцен
src/routes/bench.tsx           /bench — витрина нового мира, вне прода
```

Главная не трогается, пока `/bench` не пройдёт браузерный QA. Тот же приём, что
уже применялся в проекте для `/design`-зоны, и он себя оправдал.

## 3. Что переиспользуется без переписывания

- `CinematicStage` + `useAct` + реестр актов — ADR 0013 остаётся в силе.
- `useMotionCapability`, `EASE`.
- `sendContactToTelegram` и весь контракт формы.
- `screenshotUrl` для живых скриншотов клиентов.
- `SceneImage` — расширяется на новые имена, не переписывается.
- `container-luxe`.

## 4. Что удаляется — и только на T17+

Ничего не удаляется физически. «Удаление» означает **размонтирование**:

- `HeroScene`, `HeroCameraPlate`, `HeroLightField`, `ServicesShowcase`,
  `StudioManifesto`, `CaseShowcase`, `ProjectBuilder`, `ClosingCta` перестают
  монтироваться на `/`, файлы остаются.
- `public/media/*.mp4` остаются в репозитории.
- Токены свечения из `styles.css` вычищаются **последним шагом**, когда ни одна
  смонтированная секция их не читает.

## 5. Открытые вопросы, требующие владельца

1. **Гарнитура.** T1 предложит 2–3 варианта на четырёх языках. Это видимое
   брендовое решение.
2. **Сцена 07 (цена на главной).** Прямо противоречит решению от 2026-09-05.
   Возвращена по §10–11 нового брифа; снимается одной строкой, если решение
   «без цен на главной» в силе.
3. **Судьба маскота.** Пять плит `svc-*` уходят с главной вместе со вторым
   регистром. Если маскот — обязательная часть айдентики ELEVATE, а не
   иллюстрация конкретного постера, это меняет мир и должно быть сказано **до**
   фазы B.
