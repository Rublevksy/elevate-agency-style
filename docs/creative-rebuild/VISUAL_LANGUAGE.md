# VISUAL LANGUAGE — «Производственная лента»

Практический документ. Значения — то, что уйдёт в токены.

## 1. Цвет

Стратегия: **Committed** — одна насыщенная краска держит 30–60 % поверхности.
Не Restrained: это Persuade-поверхность, и робкий акцент на чёрном — та самая
безопасная середина, из-за которой инкумбент не держит планку.

| Роль | Значение | Где |
|---|---|---|
| `ink` | `oklch(0.65 0.18 255)` — синий ELEVATE | краска: заливки кадров, рельс, ленты, флажки, знаки. **Треть экрана и больше** |
| `ink-deep` | `oklch(0.52 0.16 255)` | тень краски на сгибе ленты, вторая прокатка |
| `stock` | `#07090D` | истинно чёрная плёночная основа, ground всей страницы |
| `stock-lift` | `oklch(0.20 0.012 260)` | приподнятая основа: ящик под рельсом |
| `window` | `oklch(0.97 0.004 260)` | **пробитое белое окно** — единственное место чужого изображения |
| `wax` | `oklch(0.96 0 0)` | восковой крест, разметка, служебные штрихи |
| `edge` | `oklch(1 0 0 / 14%)` | волосяные линии перфорации и делений |
| `on-ink` | `oklch(0.99 0 0)` **только на `ink-deep`**, не на `ink` | текст поверх краски |
| `destructive` | `oklch(0.62 0.22 27)` | только ошибки формы |

**`on-ink` — не косметика, а условие читаемости трети экрана (CRITIQUE_01 P5).**
Белое на `ink` `oklch(0.65 0.18 255)` даёт около **2.8:1** — провал AA. Поскольку
по L1 краска занимает треть экрана, нечитаемый на ней текст означает нечитаемую
треть страницы. Поэтому: текст **никогда** не ставится на чистый `ink`. Под
текстом краска берётся в `ink-deep` `oklch(0.52 0.16 255)`, где белое даёт
≈ 6.0:1. Проверяется в T4, до постройки сцен.

**Запрещено:** любые `box-shadow` с цветом, `blur`-блум, `mix-blend-screen`
свечения, градиенты «в никуда». Градиент разрешён только как **проявка** —
плотность краски по длине ленты.

## 2. Типографика

Одно семейство, один кегль, ранг через число ячеек (L7).

**Гарнитура выбрана на T1 — см. `TYPOGRAPHY.md`. Решение: одна суперсемья, две
ширины.** `Fira Sans Extra Condensed` на display, `Fira Sans Condensed` на текст
и служебное. Это не два шрифта, а две ширины одного семейства одного автора:
общий скелет, общая кириллица, один голос.

| Роль | Гарнитура | Кегль | Начертание | Трекинг | Интерлиньяж |
|---|---|---|---|---|---|
| `frame-title` | **Fira Sans Extra Condensed** | `clamp(2.2rem, 1.2rem + 4.2vw, 5.5rem)` | 700 | `-0.01em` | **0.98** |
| `frame-body` | **Fira Sans Condensed** | `1rem` | 400 | `0` | `1.55` |
| `slate` | **Fira Sans Condensed** | `0.6875rem` | 600, caps | `0.22em`, на `<480px` → `0.16em` | `1` |
| `tick` | **Fira Sans Condensed** | `0.75rem` | 500, caps, tabular | `0.14em` | `1` |

Интерлиньяж display **0.98, а не 0.96**: замерено на чешской строке в три
строки — при 0.96 карон над `ř` и `ě` подходит к базовой линии предыдущей строки
вплотную.

Трекинг `slate` снижается на мобильном: при `0.22em` служебная подпись
переносится на две строки на 390px — найдено рендером, не предположением.

`tick` поднят с `0.625rem` до `0.75rem` (CRITIQUE_01 P5): им набирается **домен
клиента** — самое ценное доказательство страницы, — и 10px капсом с трекингом
это доказательство прятали. **Домены и телефон капсом не набираются вообще.**

Покрытие проверено измерением в браузере, а не заявлено: чешская диакритика,
кириллица включая `Ж Щ Ъ Ы Э Ю Я`, и украинские `І Ї Є Ґ` — **пропусков ноль**.
Подмножество `cyrillic-ext` обязательно: без него ломается украинский.

Самохостинг обязателен, не CDN. Fallback `system-ui` отрисовывает все четыре
языка без tofu — проверено. Обоснование выбора и разбор шести отклонённых
кандидатов — в `TYPOGRAPHY.md`.

## 3. Материал

Мир состоит из четырёх материалов и больше ни из чего:

1. **Плёночная основа** — истинно чёрный носитель с крупным зерном. Зерно видно
   при 100 %, не при 400 % (L3). Реализация: один тайлящийся PNG-плейт зерна
   поверх `stock`, `opacity` ~0.10, `background-repeat`.
2. **Перфорация** — прямоугольные отверстия со скруглением 1px по краям ленты.
   Реализация: SVG-паттерн, а не картинка, — он должен быть резким на любом DPR.
3. **Краска** — плоский синий. Кладётся заливкой, лентой, крестом, флажком.
4. **Пробитое окно** — белое поле с чуть неровным краем (пробойник, не нож).
   Внутри и только внутри — фотография, скриншот, кадр.

## 4. Форма

- **Скругление: 0** везде, кроме перфорационных отверстий (1px).
- **Рамок нет.** Границей служит край плёнки или край пробитого окна.
- **Заливок-панелей нет.** Приподнятая поверхность — только ящик под рельсом.
- Пропорция кадра: **4:3** (кадр 35 мм с полем). Все окна и все генерируемые
  ассеты кратны этой сетке.

## 5. Знаки состояния (L5)

Одинаковы во всех секциях. Рисуются кодом (SVG), не генерируются.

Одинаковы во всех секциях. Рисуются кодом (SVG), не генерируются. **У каждого
обязателен `aria-label` и видимая микро-подпись на мобильном** (CRITIQUE_01 P5).

| Знак | Смысл | Где применяется |
|---|---|---|
| восковой крест | сделано / просмотрено | пройденные услуги, отвеченные шаги билдера |
| синяя лента | зафиксировано | выбранный вариант в билдере |
| сложенный флажок | ты здесь | текущая позиция на рельсе |
| булавка | отложено, но достижимо | обрезки в ящике; **обязателен на каждом обрезке**, иначе половинная плотность прочитается как «недоступно» |
| пробитый угол | **действительно недоступно** | услуга вне текущего набора. **Никогда не на кейсах** и никогда как «нет данных» (CRITIQUE_01 P2) |

**Открытый вопрос по кресту.** Критика справедливо заметила: тридцать лет
интерфейсов учат читать крест как «нет / закрыть», а «этот дубль печатаем» он
означает только для монтажёра. Проверяется на T4 вместе с текстовыми
эквивалентами; если не читается — знак заменяется, закон L5 не меняется.

## 6. Сетка и контейнер

- Полоса рельса: фиксированная высота `clamp(88px, 9vh, 132px)`, всегда на
  одной и той же вертикали внутри вьюпорта секции.
- Контейнер копии: наследуется `container-luxe` (1200px) — он работает и
  менять его нет причины.
- Шаг кадра: `--frame`, вычисляется от высоты рельса, а не задаётся отдельно.

## 7. Что уходит из инкумбента

| Уходит | Причина |
|---|---|
| `--primary-glow`, `--primary-glow-strong` | L2: свечения больше нет |
| `.shadow-ambient`, `.shadow-contact` | теней нет, глубина — наложение плёнки |
| `.surface-glass` | стеклянных панелей нет |
| `--radius*` (кроме перфорации) | скруглений нет |
| Montserrat как display | не конденсированный; геометрический гротеск, чужой этому миру |
| Inter как корпусный | заменяется Fira Sans Condensed; Inter-as-display в стоп-листе Impeccable |
| `<link>` на Google Fonts в `__root.tsx` | заменяется самохостингом из `public/fonts/` |
| четырёхплоскостной `perspective`-риг | мир плоский и печатный; глубина — стопка плёнки, а не камера в объёме |

Токены **не удаляются из `styles.css`** на этом этапе — они остаются, пока старые
секции смонтированы. Удаление — шаг последней фазы `IMPLEMENTATION_PLAN.md`.
