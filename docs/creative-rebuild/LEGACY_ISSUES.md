# LEGACY ISSUES — дрейф отброшенного мира

Реестр находок детектора Impeccable по **инкумбенту**. Снят на T1, 2026-09-05.

**Ничего из этого не чинится и не подавляется.** Причины:

1. Это код, который выводится из монтажа на T17 (`IMPLEMENTATION_PLAN` §4).
   Править типографику в мире, который решено заменить, — это polish on the
   discarded look, то есть прямо названный скиллом провал.
2. `ignore-value` означал бы «это намеренное дизайн-решение». Это не так — это
   предсуществующий дрейф. Ставить ignore, чтобы заглушить верную находку, было
   бы враньём в журнале.

Реестр существует, чтобы находки не потерялись и чтобы на T17 было видно, что
именно закрылось размонтированием, а что придётся закрыть отдельно.

**Корень — в `DESIGN.md`, а не в компонентах.** Я записал рампу четырьмя ролями
(`display` / `headline` / `body` / `label`), тогда как инкумбент фактически
использует больше ступеней. Детектор честно ловит расхождение с документом;
документ — сжатая запись инкумбента, а не полная его инвентаризация.
Достраивать инвентарь умирающей рампы — работа впустую.

**Как закроется.** Шесть из девяти находок живут в `src/styles.css` и уйдут
вместе с чисткой токенов на последнем шаге; три живут в компонентах, которые
размонтируются на T17. Новая рампа (`TYPOGRAPHY.md` §4) состоит из четырёх ролей
и ни одного литерала вне их — дрейфа этого класса в новом мире быть не может по
построению.
