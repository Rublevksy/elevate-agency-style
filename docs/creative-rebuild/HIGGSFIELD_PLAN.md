## 2. Выбор модели по типу ассета

Модели выбраны из живого каталога, параметры — из их фактических схем.

### ENVIRONMENT / STILL (A1–A6) → `nano_banana_pro`

| Поле | Значение |
|---|---|
| **Модель** | `nano_banana_pro` (Google, «Ultimate quality, text and diagrams») |
| **Почему** | Единственный из фотореалистичных, который сочетает **три** нужных свойства: `image_references` в `medias` (механизм консистентности серии), `4:3` в `aspect_ratios`, и `4k` в `resolution`. Плюс проверенный в этом проекте путь: hero-мастера сделаны reference-guided на `nano_banana` |
| **Вход** | A1: только промпт. A2–A6: промпт + `medias: [{role: "image_references", value: <media_id A1>}]` |
| **aspect_ratio** | `4:3` |
| **resolution** | `4k` для финала, `2k` для разведочных кадров |
| **Стоимость** | **4 кр.** (4k), **2 кр.** (2k) — снято `get_cost` |
| **Ожидаемый выход** | 4:3 фотореалистичный кадр рабочей поверхности сверху |

**Отклонённые кандидаты и причина:**

| Модель | Почему не она |
|---|---|
| `seedream_v4_5` | 1 кр. и 4K, `image_references` есть — **держим как запасную**, если `nano_banana_pro` не даст стабильности серии. Не первая, потому что у `nano_banana_pro` сильнее контроль материала |
| `gpt_image_2` | силён в тексте и типографике — ровно то, чего в кадре **не должно быть** |
| `recraft_v4_1` | `medias: []` — референс подать нельзя, значит серию не свести |
| `soul_2`, `soul_cast`, `soul_cinematic` | про людей и идентичность персонажа; в кадре нет лиц |
| `flux_2` | хорош, но `aspect_ratios` без `4:3`… содержит `4:3` — держим третьей запасной |
| `marketing_studio_image`, `ms_image` | рекламные форматы и brand-kit-промпты; чужая задача |
| `z_image` | стилизованный и быстрый, не фотореалистичный |

### TILING TEXTURE (G1 зерно) → **не генерируется**

Генерация даёт нетайлящееся изображение. Зерно делается процедурно
(canvas-шум → PNG 256×256) скриптом в `scripts/`. Это дешевле, точнее и
перекрашивается.

### IMAGE-TO-VIDEO (M1, опционально) → `seedance_2_0`

| Поле | Значение |
|---|---|
| **Модель** | `seedance_2_0` |
| **Почему** | Проверена в этом проекте: `hero-open.mp4` снят ею, поведение `start_image`, `duration`, `resolution`, `aspect_ratio`, `generate_audio` известно фактически, а не по памяти |
| **Вход** | `medias: [{role: "start_image", value: <media_id A1>}]` |
| **Параметры** | `duration: 5`, `resolution: 720p`, `aspect_ratio: 4:3`, `generate_audio: false`, `mode: std` |
| **Стоимость** | ~22.5 кр. (замерено на 3:4; 4:3 подтверждается `get_cost` перед запуском) |
| **Статус** | **отложено.** Решается только после сборки сцены 02 кодом |
| **Важно** | у `seedance_2_0` **нет** `negative_prompt` — запреты сворачиваются в текст промпта прозой. Зафиксировано фактом в `node-04-generation-spec.md` |

### ABSTRACT / GRAPHIC / UI VISUAL → **не требуется**

В этом мире нет абстрактных или UI-ассетов: рельс, знаки и окна — код,
клиентские сайты — реальные скриншоты.

### TRANSITION SHOT → **не требуется**

Переход — протяжка ленты, то есть `transform`. Генерировать переход было бы
подменой механики картинкой.

## 3. Известные подводные камни канала

Собраны из фактического опыта проекта, не из предположений:

1. **Сервер может подменить запрос пресетом.** На Node 04 запрос был перехвачен
   предложением пресета «3D RENDER» — первого пункта списка запретов. Лечится
   `declined_preset_id` в повторном вызове. **Ожидать этого и на изображениях.**
2. **`get_cost: true` задание не создаёт** — обязателен перед каждым новым типом
   запроса.
3. **Локальный файл подаётся через `media_upload` → PUT → `media_confirm`**, а не
   через виджет: это Claude Code, не Apps UI, и файл лежит в репозитории.
4. **Модель почти наверняка попытается написать текст на распечатках.** Это
   главный риск серии. Запреты идут прозой в промпт; критерий приёмки 1
   блокирующий.

## 4. Этапность (обязательна)

| Фаза | Что | Кредиты | Гейт |
|---|---|---|---|
| **A** | творческая разведка — **завершена**, 0 кр. | 0 | эти документы |
| **B** | 2–3 варианта A1 на 2k, выбор мастера | 4–6 | владелец смотрит кадр |
| **C** | визуальный QA A1: глифы, свет, зерно, пропорция | 0 | критерии приёмки `ASSET_PLAN` §6 |
| **D** | A1 в 4k + A2…A6 reference-guided | 24 | покадровая приёмка |
| **E** | M1 — только если сцена 02 этого потребует | 0 или 22.5 | решение после сборки |
| **F** | интеграция, конвертация в webp, браузерный QA | 0 | — |

**Между B и D — обязательная остановка.** Пять кадров, сведённых по неверному
мастеру, — это пять кадров брака; проверка мастера стоит 0 и экономит всю серию.

## 5. Первая команда следующего этапа

Ничего не запускать, пока концепция не утверждена. Первая команда после
утверждения — **одна**, разведочная:

```
mcp__higgsfield__generate_image
  model: nano_banana_pro
  aspect_ratio: "4:3"
  resolution: "2k"
  count: 3
  prompt: <промпт A1 из ASSET_PLAN, запреты прозой>
```

Стоимость: 3 × 2 = **6 кредитов**. Это весь расход фазы B.
