# ASSET PLAN — «Монтажный стол»

Правило отбора: **ассет генерируется только если код не может дать результат
лучше.** Всё, что должно быть резким на любом DPR и перекрашиваться токеном, —
код.

## 1. Что делается кодом (не генерируется)

| Элемент | Почему код | Реализация |
|---|---|---|
| Перфорация | должна быть резкой на 1×/2×/3× и перекрашиваться | SVG `<pattern>` |
| Рельс, кадровые деления | то же | SVG + CSS |
| Восковой крест, синяя лента, флажок, булавка, пробитый угол | пять знаков, каждый перекрашивается и анимируется | инлайн SVG |
| Зерно `G1` | **должно тайлиться**; генерация даёт нетайлящееся изображение | процедурный canvas-шум → один PNG 256×256, скрипт в `scripts/` |
| Обрыв перфорации (сцена 08) | зависит от ширины вьюпорта | `clip-path` |
| Скриншоты клиентских сайтов | это реальные сайты | существующий `screenshotUrl` (mshots) |
| Логотип ELEVATE | бренд | существующий SVG |

Сравните с инкумбентом: там производные слои света (`hero-light`, `hero-atmo`)
делались скриптом из растра. Здесь производных слоёв нет вообще — свет не
рисуется, потому что свечения нет (L2).

## 2. Что генерируется

Шесть кадров. Все 4:3. Все — **одна и та же съёмочная логика**: вид сверху на
рабочую поверхность студии, один жёсткий направленный источник, крупное зерно,
ни одного читаемого глифа, ни одного лица, ни одного чужого товарного знака.

| ID | Сцена | Содержание | Обязателен |
|---|---|---|---|
| **A1** | 01 ЗАПРАВКА | распечатки макетов, линейка, нож, обрезки | да — первый экран |
| **A2** | 03 WEB | распечатанные вайрфреймы, сетка, карандаш | да |
| **A3** | 03 SEO | распечатки позиций и логов, маркер, линейка | да |
| **A4** | 03 E-SHOP | упаковочная коробка, этикетка, ценник без цифр | да |
| **A5** | 03 BRANDING | раскладка вариантов знака, образцы краски | да |
| **A6** | 03 APPLICATIONS | распечатки экранов встык, ножницы | да |

**A1 — мастер серии.** Он генерируется первым и дальше подаётся как
`image_references` во все остальные. Это и есть механизм консистентности: не
повторение слов в промпте, а буквальная передача кадра.

Тот же приём уже проверен в этом проекте: `references/generated/*-master.png`
сделаны reference-guided на `nano_banana`.

## 3. Опциональный ассет

| ID | Что | Решение |
|---|---|---|
| **M1** | движение протяжки, image-to-video из A1 | **отложено.** Решается после того, как A1–A6 приняты и сцена 02 собрана кодом. Если протяжка кодом читается — M1 не нужен вовсе |

Причина отложить: сцена 02 — это движение **плоской ленты по столу**. Такое
движение код делает точнее и дешевле, чем видео, и без веса в 3 МБ. Видео здесь
оправдано только если понадобится физика материала (провис, дрожание плёнки),
а это проверяется только на собранной сцене.

## 4. Судьба существующих ассетов

**Ничего не удаляется.** Все существующие ассеты остаются на диске и в git
(`cb506da`).

| Ассет | Судьба |
|---|---|
| `public/media/hero-camera.mp4`, `hero-open.mp4`, `hero-transition.mp4` | остаются в репозитории, **перестают монтироваться** |
| `references/generated/*-master.png` | остаются; исходники ADR 0011 |
| `src/assets/refs/hero-*` | остаются; перестают использоваться на главной |
| `src/assets/refs/svc-*` | остаются; **перестают использоваться на главной** |
| `/references/*.png` | не менялись и не меняются |

**Отдельно про `svc-*`.** Пять сервисных плит с маскотом — второй визуальный
регистр, из-за которого страница разваливалась (`DESIGN.md`). Новый мир их не
использует. Это не удаление ассета, а смена того, что смонтировано; они остаются
доступны на страницах услуг, где живут в своём контексте и ни с чем не спорят.

Побочный эффект: юридический дефект `svc-eshop` (чужой товарный знак и вшитый
чешский маркетинг в кропе) с главной уходит вместе с плитой, без всякого
компромисса с кадрированием.

## 6. Спецификация приёмки ассета

Кадр принимается только если выполнено всё:

1. **Ни одного читаемого глифа.** Проверяется просмотром 1:1. Сайт
   четырёхъязычный; текст в растре ломает и i18n, и SEO.
2. **Ни одного чужого товарного знака и ни одного лица.**
3. Пропорция ровно 4:3.
4. Свет, высота камеры и материал поверхности совпадают с A1.
5. Верхние 15 % кадра — рабочее негативное пространство под восковой крест.
6. Зерно видно при 100 %.
7. Вес после конвертации в webp ≤ 220 КБ на кадр.

Проверка — покадрово, локально, теми же драйверами в
`.autopilot/cinematic-foundation/`. **0 дополнительных кредитов на проверку.**
