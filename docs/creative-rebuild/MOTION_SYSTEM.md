# MOTION SYSTEM — «Производственная лента»

Каждое движение отвечает на вопрос «что делает лента / стол / метка». Движение,
на которое нет ответа, не делается.

## 1. Одни часы (L9)

Единственный источник времени — `act.progress` от `CinematicStage`. Ничто на
странице не анимируется по собственному таймеру, кроме двух исключений:

1. **защёлка ленты** — rAF-сглаживание к дискретной цели (см. `CAMERA_SYSTEM` §4);
2. **знаки состояния** — одноразовые переходы на клик, 180 мс.

`setInterval` запрещён. Автолистание запрещено: лента идёт только тогда, когда
её тянет посетитель.

## 2. Кривая

Одна: `EASE = cubic-bezier(0.22, 1, 0.36, 1)`, импортируется из
`@/components/cinematic`. Второй кривой в проекте не появляется.

Исключение — **защёлка**: экспоненциальное сглаживание `head += (target - head) × 0.18`
за кадр. Это не кривая анимации, это фильтр положения.

## 3. Словарь движений

Всего шесть. Больше вводить нельзя.

| Движение | Что означает | Свойство | Длительность |
|---|---|---|---|
| **ПРОТЯЖКА** | лента идёт | `transform: translateX` ленты | привязано к скроллу |
| **ЗАЩЁЛКА** | кадр сел на место | тот же `translateX`, фильтр | ~250 мс до покоя |
| **ПРОЯВКА** | материал набирает плотность | `opacity` слоя краски | привязано к скроллу |
| **МЕТКА** | состояние изменилось | `clip-path` штриха / `scaleX` ленты | 180 мс |
| **ПОДЪЁМ** | обрезок поднят из ящика на рельс | `translateY` + `opacity` | 420 мс |
| **ОБРЫВ** | материал кончился | `clip-path` края перфорации | привязано к скроллу |

## 4. Что запрещено

- `opacity: 0 → 1` как способ появления секции. Появление — это **приход кадра**.
- Любое свечение: `box-shadow` с цветом, `filter: blur` как блум,
  `mix-blend-screen` поверх краски.
- Параллакс на курсор.
- Плавающие/дышащие декоративные элементы.
- `scale` как «оживление» при наведении.
- Анимация, которая читается только при быстром скролле.
- Перехват скролла (`scroll-jacking`), `scroll-snap` на уровне страницы.

## 5. Драматургия плотности

Плотность краски — главный носитель эмоции, и она проходит через всю страницу
одной дугой, а не сбрасывается в каждой сцене:

```
00 АППАРАТУРА  0.5   постоянная кромка, вне дуги
01 ЗАПРАВКА    0.55  краска легла, лента ещё не проявлена
02 ЛИНИЯ       0.55 → 0.85  нарастает по мере протяжки; на каждом стыке кадров
                     кратко падает до 0.62; кадр ЦЕНЫ — 1.0, он ярчайший в сцене
03 СДАНО       0.80  поднятый проект 1.0, висящие 0.5
04 ПАУЗА       0.25  минимум страницы, выдох — объявленное исключение из L1
05 СБОРКА      0.25 → 1.0  растёт с каждым зафиксированным ответом
06 КОНЕЦ       1.0 → 0  падает к правому краю — второе исключение из L1;
                     свет не гаснет, кончается материал
```

Это единственный сквозной параметр страницы. Реализуется одной CSS-переменной
`--density`, которую акт выставляет, а слои краски читают.

## 6. Метки состояния — движение

Знаки рисуются SVG и появляются одинаково везде:

- **восковой крест** — два штриха, `clip-path` слева направо, 180 мс, с
  задержкой 40 мс между штрихами. Читается как «прочерк рукой».
- **синяя лента** — `scaleX` от 0, origin left, 180 мс.
- **сложенный флажок** — без анимации появления: он **едет** вместе с лентой,
  потому что он и есть позиция.
- **пробитый угол** — статичен всегда. «Данных нет» не анимируется.

## 7. Производительность

- Анимируются только `transform` и `opacity`. `clip-path` — только на знаках
  (маленькие элементы, редкие события).
- `will-change: transform` — только на ленте, снимается на покое.
- Зерно — один тайлящийся PNG в `background-repeat`, не `filter`, не SVG-фильтр.
- Ни `backdrop-filter`, ни WebGL, ни canvas-цикла на странице.
- Бюджет: главная должна держать 60 fps на среднем Android при `motion`.

## 8. Уровни движения

Наследуется `useMotionCapability` без изменений:

- **`cinematic`** — всё выше плюс, если ассет M1 будет сделан, скраб клипа
  протяжки на стыке сцен 01→02.
- **`motion`** — всё выше без видео. Лента, защёлка, проявка, метки работают:
  они дешёвые.
- **`still`** — только `prefers-reduced-motion`. Лента стоит, страница
  разложена вертикально, все метки на месте. См. `CAMERA_SYSTEM` §7.

Важно: `motion` **не** теряет ленту. В инкумбенте слабая машина теряла только
скраб видео, и этот принцип сохраняется — здесь терять нечего, потому что вся
механика на `transform`.
