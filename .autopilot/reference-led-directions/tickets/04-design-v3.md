## Что должно заработать

Маскот — **ведущий, который показывает вам работу**, а интерфейс рядом с ним настоящий и переключается вместе с ним. Отличие от V1/V2: там скролл ведёт повествование, здесь ведёт **взаимодействие** — клик/hover/клавиатура.

Открой все пять `references/*_SERVICE_*_HERO.png` — обрати внимание, что на каждой маскот показывает на своё устройство: это и есть механика направления.

1. **Hero** — разворот:
   - С одной стороны — **живой browser-window**: настоящая DOM-вёрстка интерфейса (шапка окна с точками, адресная строка, содержимое), **не картинка**.
   - С другой — `<RefImage>` сцены с маскотом, который «показывает» на это окно.
   - Оба слоя реагируют на курсор лёгким **разнонаправленным** parallax (маскот и окно смещаются по-разному — даёт глубину).
   - Заголовок компактный, окно доминирует.
2. **Пять услуг = пять табов.** Переключение (клик, hover, `Tab`+`Enter`/`Space`) **одновременно** меняет три вещи:
   - **сцену маскота** — кроссфейд + лёгкий scale между пятью реальными фото (`svc-web`, `svc-seo`, `svc-eshop`, `svc-branding`, `svc-app` в порядке `t.ui.serviceStage`);
   - **содержимое browser-window** — живой UI под конкретную услугу (веб: макет страницы с CTA; SEO: график роста; e-shop: сетка товаров; branding: палитра+знак; app: экран приложения). Минимум 3 из 5 визуально принципиально разные;
   - **акцентную подпись** рядом.
   Автолистание с паузой на hover/focus/после первого клика.
3. **Scroll storytelling** — скролл ведёт «по столу»: окно живёт дольше одного экрана (лёгкий `sticky`), затем доказательный блок **встроен в тот же интерфейс** (как панель внутри окна, не отдельной секцией с иконками), затем CTA.
4. **CTA** — на `/contact`.

Шрифты — своим `head()` маршрута: display **Space Grotesk** или **DM Sans**; тело Inter.

`<ExploreSwitcher active="design-v3" />` монтируется страницей.

## WOW-момент (обязателен, назови его в возврате)

Маскот физически меняет сцену вместе с интерфейсом — пять разных реальных фотосцен переключаются как кадры одной съёмки, синхронно с живым UI.

## Критерии приёмки

- [ ] Browser-window — живой DOM, не изображение
- [ ] Сцена маскота — реальное фото через `RefImage`, меняется при переключении услуги
- [ ] Переключение меняет и сцену, и содержимое окна, и подпись — одновременно
- [ ] Минимум 3 из 5 состояний окна визуально принципиально разные
- [ ] Курсор-parallax разнонаправленный на двух слоях, гейтится `useReducedMotion()`
- [ ] Табы доступны с клавиатуры (`Tab`/`Enter`/`Space`), видимый focus-ring из палитры, `role="tablist"/"tab"/"tabpanel"`
- [ ] Доказательный блок встроен в интерфейс, а не отдельная секция icon-карточек
- [ ] Автолистание останавливается на hover/focus/после клика и при reduced-motion
- [ ] Весь текст из `useT()`; выдуманных цифр в DOM нет
- [ ] Адаптив: на мобильном окно и сцена перестраиваются, а не сжимаются
- [ ] `tsc --noEmit` — 0 ошибок
