## Что должно заработать

Не страница с секциями, а **фильм из глав**. Тот же референс-материал, но подача принципиально другая, чем у V1: там композиция из аккуратных карточек — здесь полнокадровое кино.

Открой референсы, чтобы видеть материал: `references/01_HOME_DESKTOP_HERO.png` и все пять `references/*_SERVICE_*_HERO.png`.

1. **Hero** — `<RefImage name="hero-macbook" priority />` **на весь экран** (`h-screen`, `object-cover`), не колонка. Медленный ken-burns push-in (scale 1 → 1.08 за ~20с, петля или один проход). Поверх — скрим-градиент снизу для читаемости и крупный **serif**-заголовок, появляющийся **по словам** (stagger). Тонкий mono-датлайн сверху. Индикатор скролла внизу.
2. **Пять глав услуг** — каждая занимает **целый экран**:
   - Сцена с маскотом (`svc-*` по порядку `t.ui.serviceStage`) на весь кадр через `<RefImage>` + скрим.
   - Крупная цифра главы (01…05), serif-заголовок услуги, короткий тег.
   - **Текст закреплён (pinned)**, пока изображение продолжает двигаться: parallax + лёгкий scale. Реализация — `useScroll` с `target` на секцию + `sticky` внутренний слой.
   - Переход между главами — **киношный**: масштаб + затемнение (не простой fade, не просто появление).
3. **Доказательный блок** — разворот крупной serif-типографикой на `t.results`, без иконок и карточек.
4. **CTA** — финальный кадр, крупно, на `/contact`.

Шрифты подключаются **своим `head()` маршрута** (не трогать `__root.tsx`): serif display — **Newsreader** или **Fraunces**; mono для номеров/подписей — **Space Mono** или **IBM Plex Mono**; тело — унаследованный Inter.

`<ExploreSwitcher active="design-v2" />` монтируется страницей.

## WOW-момент (обязателен, назови его в возврате)

Полнокадровая смена глав с закреплённым текстом — ощущение монтажной склейки, а не скролла по секциям.

## Критерии приёмки

- [ ] Hero — полноэкранное реальное фото с ken-burns, не колонка с картинкой
- [ ] Заголовок появляется по словам, serif-гарнитура подключена через `head()` маршрута
- [ ] Пять полноэкранных глав, в каждой — реальная сцена с маскотом на весь кадр
- [ ] Текст главы закреплён (pinned), пока изображение движется — это видно на скролле
- [ ] Переход между главами масштабно-затемняющий, не простой fade
- [ ] Ни одной CSS-имитации фотографии; ни одной icon+heading+text карточки как структуры
- [ ] Никакого градиентного текста, никакого декоративного blur
- [ ] Весь текст из `useT()`; выдуманных цифр в DOM нет
- [ ] `prefers-reduced-motion`: parallax/ken-burns отключаются, главы становятся обычным вертикальным потоком
- [ ] Мобильная раскладка не ломает pinned-логику (допустимо линеаризовать)
- [ ] `tsc --noEmit` — 0 ошибок
