# Elevate Digital Studio

Create a modern, high-end website for a digital agency called "ELEVATE".

STYLE:
- Dark, minimal, premium design
- Background color: #0B0F1A (dark navy)
- Primary color: #3B82F6 (blue)
- Text: white and light gray
- Clean, minimal, no unnecessary effects
- Professional, corporate (NOT gaming style)
- Smooth subtle animations (fade, hover glow)
- A lot of spacing (luxury feel)

FONT:
- Use Inter font
- Headings: Bold
- Text: Regular

LAYOUT:
- Perfect alignment and grid
- Clean UI, no clutter
- Modern SaaS / agency look

LANGUAGE SWITCH:
Add language switch in top right:
CZ | EN | RU | UA
(no flags, only text)
